# 분산 복원 실험 리포트 (Phase B)

- 작성일: 2026-11-23
- 벤치마크: **임시 벤치마크 (샘플 200건)** — 통계청 실측이 아님 (`benchmark-data.md` 참조)
- 베이스라인: 분포추출 전략 + Gemini `gemini-2.5-flash-lite`, temperature 0.7,
  n=200, 배치 10, 시드 20261123 (수치는 `baseline-report.md` 참조)
- 실험 순서: 계획 §4에 따라 A-1 → A-3 → A-2 순으로 진행.
  피주임 검토 반영 (2026-11-23): **A-1은 확인만 하고, A-3·A-2를 중심으로
  실험한다.** A-1 추가 실험은 하지 않는다.

## 0. 핵심 결론 (한 줄)

**이 벤치마크에서는 분산 붕괴 자체가 없어서, 분산을 넓히는 모든 방법이
평균·JSD를 악화시키거나 무의미했다. A-3 평탄화는 버리고, A-2 혼합은 중립,
A-1 온도 1.3은 잡음 수준의 미미한 개선에 그쳤다.** 분산 복원은 붕괴가 재현되는
벤치마크(논쟁적 문항·동질 페르소나)에서 다시 검증해야 한다.

## 2. 방법별 분석

### A-1 온도 조절 (temperature 0.7 → 1.3) — 라이브 실험

- 구현: `core/providers.py`의 `generate()`·`AIProvider.generate()`·`_call_rest()`에
  선택적 `temperature` 인자 추가 (기본값 0.7 유지, 기존 동작 변경 없음).
  로컬 CLI는 temperature를 0.7로 하드코딩하고 있어, 라이브 실험은 CLI와 동일한
  승인 인증 경로(서로게이트, `dynamic_credentials` 헬퍼)로 Gemini REST를 직접
  호출하는 `benchmarks/run_temperature.py`로 수행했다.
- 결과: 평균 오차 0.102→0.088, SD 비율 1.018→1.002, JSD 0.0151→0.0122로
  숫자상으로는 소폭 개선됐으나, 문항별로는 엇갈렸다
  (Q3 평균 오차 0.13→0.03 개선 vs Q1 JSD 0.005→0.018 악화, Q6 평균 오차
  0.17→0.215 악화). 리플레이-라이브 간 잡음 폭(JSD ±0.004)과 비슷한 크기라
  **실질적 효과 없음**으로 판단한다.
- 부분 데이터 분석(처음 70명, 동일 페르소나 paired 비교): 온도 1.3이 추출
  확률분포 자체를 평탄하게 만들지 않았다. 페르소나별 최빈값 확률 평균은
  Q1 0.460→0.507, Q3 0.477→0.465, Q4 0.511→0.501, Q6 0.397→0.401로 사실상
  동일하고 엔트로피도 ~1.8 bits로 변화가 없다. LLM이 텍스트로 내놓는 확률
  숫자 자체가 온도에 둔감한 것으로 보인다.
- 실행 중 장애: 1차 시도에서 2번째 호출이 429 6회 연속으로 실패해 중단,
  2차 시도에서 503으로 중단됐다가, 재시도 조건(429/503/타임아웃)에 503을
  추가하고 호출 간 8초 간격을 둔 3차 시도에서 완료됐다. 무료 등급 할당량
  불안정 탓이며, 재현 시 같은 우회가 필요하다.
- 비중: **확인만** — 이 실험으로 온도 조절의 효과를 확인했으므로 추가
  실험은 하지 않는다 (피주임 검토 반영, 2026-11-23).

### A-3 반최빈값 보정 — 버린다 (회귀 테스트 탈락)

- 구현: `core/variance.py`의 `flatten_distribution()`(균등분포 쪽 선형 보간),
  `temperature_scale()`(p^(1/T) 거듭제곱 보정),
  `calibrate_flattening()`·`calibrate_temperature()`(학습 분포 대조 계수 선택).
- 결과: α·T가 커질수록 평균 오차와 JSD가 **단조 악화**되고 SD 비율은 1을
  넘어 과분산이 된다. SD 비율이 이미 ~1.0인 분포를 더 넓히면 실측에서
  멀어지는 것이 당연한 결과다. 학습 분포로 보정 계수를 정해도 마찬가지다
  (집계 추출분포 대조 시 최적 α는 Q1 0.1 / Q3 0.0 / Q4 0.0 / Q6 0.2,
  최적 T는 1.0~1.5 — 즉 "거의 보정하지 않는 것"이 최적이다).
- 판정: **이 벤치마크에서는 적용하지 않는다.** 단, 코드 자체는 유효하며
  붕괴가 관측되는 벤치마크에서는 다시 쓸 수 있게 `core/variance.py`에
  남겨둔다. 보정 계수를 벤치마크와 같은 데이터로 정하면 과적합이 되므로,
  실전 적용 시에는 별도 문항·별도 데이터로 계수를 정해야 한다
  (`calibrate_flattening` 독스트링에 명시).

#### 분포 왜곡·문항 간 일관성·희소 셀 (피주임 검토 반영, 2026-11-23)

- **분포 왜곡**: α·T가 커질수록 평균 오차 단조 악화(0.170→0.390) + SD 비율
  1.0 초과 과분산(최대 1.249) — 결과표 참조. 평탄화는 분포를 넓히는 대신
  실측 분포에서 멀어지게 만든다.
- **희소 셀 부풀림** (집계 추출분포 기준): Q4 '전혀 그렇지 않다' 0.036 →
  α=0.3에서 0.085(×2.35), α=0.5에서 0.118(×3.25). Q3 '전혀 그렇지 않다'
  0.049 → α=0.3에서 0.094(×1.93). Q1 '11번가' 0.073 → α=0.3에서
  0.111(×1.52). 희소 선택지가 2~3배로 부풀려진다. 페르소나별로는 더 클 수
  있다 (p=0.01인 보기 → α=0.3에서 0.067, ×6.7).
  **Fallback 규칙**: 현재 `flatten_distribution()`에는 희소 셀 보호 하한이
  없다. 붕괴 벤치마크에서 A-3을 다시 쓸 때는 최소 확률 하한(floor) 또는
  α 상한 같은 fallback 규칙을 먼저 정해야 한다.
- **문항 간 일관성**: Q3(만족도)-Q4(재이용 의향) Spearman — 실측 −0.006
  (사실상 무상관), 합성 베이스라인 0.062, 리플레이(α=0) 0.132, 평탄화
  α=0.3 → 0.109, α=0.5 → 0.081. 평탄화가 상관을 소폭 약화시키는 방향이나,
  실측 상관 자체가 ≈0이라 이 벤치마크에서는 일관성 저하를 판정할 수 없다.
  문항 간 일관성 지표는 KOSIS 집계표만으로는 측정 불가 — MDIS
  마이크로데이터 필요 (계획 §6, 목표 실측 상관계수 ±0.2 이내).
- **쿼터 희소 셀 fallback** (Phase 2, 같은 지적의 다른 갈래 — 확인 완료):
  제주 70대 이상 여성 풀 11건에 15건 요구 시 정확 셀 11건 + 같은 권역
  다른 시도(강원) 4건으로 채움 (완화 level='province'). 건수 쿼터 3셀 동시
  적용 시 목표 정확 달성 (3/3, 2/2, 5/5).

### A-2 혼합 샘플링 — 중립 (효과 없음, 해로움도 없음)

- 구현: `core/variance.py`의 `assign_tendency()`(성향 가중 추첨),
  `mixture_adjust()`·`mixture_sample()`(성향별 재가중).
  기본 성향 비율은 다수 0.6 / 소수 0.3 / 극단 0.1 (임시 벤치마크의 최빈값
  점유율에서 역산한 출발점 — `DEFAULT_TENDENCY_WEIGHTS`).
  성향은 페르소나당 1회만 추첨해 전 문항에 동일하게 적용한다
  (문항별 추첨은 "한 사람이 문항마다 성향이 바뀌는" 모순이라 제외).
- 결과: 강도 0.5에서 리플레이와 사실상 동등(JSD 0.0115 vs 0.0109,
  평균 오차 0.135 vs 0.137). 강도 1.0에서는 JSD가 소폭 악화됐다.
  분산이 이미 살아 있어 섞을 "소수 의견"의 여지가 없는 상태에서는
  혼합이 분포를 바꾸지 못한다.
- 판정: **채택도 폐기도 보류.** 붕괴 벤치마크에서 재검증할 것.
- 비중: **중심 실험** (A-3과 함께 — 피주임 검토 반영, 2026-11-23).

## 3. 왜 분산 복원이 "필요 없게" 나왔나

1. 분포추출 전략 자체가 이미 분산을 살린다 (베이스라인 리포트 §해석 참조).
   페르소나별 추출 분포의 최빈값 확률 평균이 0.40~0.51, 엔트로피 ~1.8 bits로
   과도하게 뾰족하지 않다.
2. 벤치마크 주제(온라인 쇼핑)가 온화하고 페르소나가 이질적이라, Li 등(2025)의
   붕괴 조건(논쟁적 이슈·동질 집단)이 성립하지 않는다.
3. 따라서 Phase B의 올바른 결론은 "방법이 틀렸다"가 아니라
   **"측정 대상이 틀렸다 — 붕괴를 재현하는 벤치마크가 먼저 필요하다"**이다.
   후속 과제: 논쟁적 문항(예: 사회조사 가치 판단 문항) 또는 동질 페르소나
   셀(예: 동일 성별·연령·직업 200명)로 붕괴를 재현한 뒤 A-1·A-2·A-3을
   다시 재는 것. MDIS 사회조사 마이크로데이터가 확보되면 그 문항으로
   재현이 가능하다.

## 4. 연결 방법 (기존 전략 클래스에 끼워넣는 방법 — 메모)

이번 작업에서는 `core/strategies.py`·`core/services.py`를 건드리지 않았다.
아래는 검증된 함수를 실전에 연결할 때의 방법이다.

### A-1 온도 (구현 완료, 연결만 남음)

- `core/providers.py`에 이미 선택적 `temperature` 인자가 있다
  (`generate(provider_id, prompt, model, timeout, temperature=0.7)`).
- 연결: `GenerationContext`에 `temperature: float = 0.7` 필드를 추가하고
  (이 작업은 `strategies.py` 수정이라 이번 갈래 범위 밖),
  `text_generate()`에서 `providers_mod.generate(..., temperature=ctx.temperature)`로
  전달한다. REST 경로에서만 동작하고, 로컬 CLI 경로는 CLI가 0.7로
  하드코딩하고 있어 무시된다 — CLI 경유 온도 실험이 필요하면
  `benchmarks/run_temperature.py` 방식을 쓴다.

### A-3 반최빈값 보정 (연결 방법)

- `DistributionElicitationStrategy.generate()`에서 `probs_from_elicited()`로
  얻은 분포에 `variance.flatten_distribution(probs, alpha)` 또는
  `variance.temperature_scale(probs, T)`를 적용한 뒤
  `sample_from_elicited()`로 샘플링한다.
- α·T는 `calibrate_flattening()`·`calibrate_temperature()`로 학습 분포와
  대조해 정하되, **보정 대상 문항과 다른 문항·데이터**로 정한다 (과적합 방지).
- 다중선택 문항은 simplex가 아니라 보기별 독립 확률이므로, `flatten_distribution`
  대신 보기별 `p' = (1-α)p + α·0.5`를 쓴다 (`run_variance_experiments.py`의
  `_multi_flatten` 참조).

### A-2 혼합 샘플링 (연결 방법)

- `DistributionElicitationStrategy.generate()`에서 배치 시작 시 페르소나마다
  `variance.assign_tendency(rng, weights)`로 성향을 1회 추첨하고,
  `probs_from_elicited()`로 얻은 분포에 `variance.mixture_adjust(probs, tendency)`
  를 적용한 뒤 샘플링한다.
- 성향 비율(weights)은 실측 분포의 최빈값 점유율에서 추정한다.
  현재 기본값 0.6/0.3/0.1은 임시 벤치마크 기준 출발점이다.
- 다중선택 문항은 보기별 Bernoulli 재가중을 쓴다
  (`run_variance_experiments.py`의 `_multi_mixture` 참조).
