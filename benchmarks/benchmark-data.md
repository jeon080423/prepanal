# 벤치마크 데이터 출처 · 접근 결과

- 작성일: 2026-11-23
- 담당: 갈래 2 (분산복원) — Phase A
- 결정 근거: 고도화 계획 §8 결정 1 — "검증용 벤치마크는 통계청 자료 사용"

## 0. 역할 분리 — KOSIS vs MDIS (피주임 검토 반영, 2026-11-23; MDIS 이용 불가 확정, 2026-11-23 이사님 결정)

- **KOSIS 공개 집계표 = 문항별 주변분포 참조용.** 주제별 주변분포(마지널)
  표만 제공하므로, 문항별 분포 비교에는 쓸 수 있다.
- **MDIS 사회조사 마이크로데이터 = 이용 불가.** 응답자 단위 데이터라야
  문항 간 상관계수·결합분포를 잴 수 있으나, 이사님 결정으로 MDIS는 쓰지 않는다.
- **문항 간 일관성(상관계수) 지표는 측정하지 않음 — MDIS 이용 불가로
  KOSIS만으로는 측정이 안 되고, 대신 한계로 남긴다.**
- 임시 벤치마크(샘플 200건)는 행 단위 데이터라 Q3-Q4 상관을 재볼 수는
  있었으나, 실측 상관이 −0.006으로 사실상 0이라 일관성 저하 판정의 기준이
  되지 못한다 (실험 리포트 A-3절 참조).

## 1. 후보 확인 결과

### (a) KOSIS 공개 집계표 — 접근 가능하나 이번 벤치마크에는 부적합

- 확인 방법: 2026-11-23 웹 검색 + KOSIS 통계목록 페이지 직접 조회
  (`kosis.kr/statisticsList/statisticsListIndex.do`).
- 결과: **로그인 없이 통계 목록 조회·집계표(CSV/XLS) 다운로드가 가능한 것은 확인됨.**
  사회조사(지자체 사회조사 포함) 등 주제별 통계가 공개돼 있다.
- 부적합 이유:
  1. KOSIS 집계표는 **주제별 주변분포(마지널) 표**다. 응답자 단위(row-level) 데이터가
     아니라, 설문지 전체에 대한 합성 응답 생성 → 문항별 분포 비교라는 이번 벤치마크
     구조에 그대로 쓸 수 없다.
  2. 공개된 사회조사 문항(생활 만족도, 사회 신뢰 등)과 앱 내 샘플 설문(온라인 쇼핑
     만족도)은 주제가 달라 문항을 1:1로 맞출 수 없다. KOSIS 문항에 맞춘 새 설문지를
     만드는 것은 가능하지만, 그 문항들의 집계표 추출은 KOSIS 사이트의 JS 기반
     표 선택 UI를 통한 대화식 작업이라 이 환경에서 자동화가 안 된다.
  3. 집계표는 성별·연령별 교차표 형태로 제공되는 경우가 많아, 단일 문항의 전체
     분포를 얻으려면 표를 직접 골라 다운로드해야 한다.
- 결론: KOSIS 집계표는 **참조 분포**로는 쓸 수 있으나, 이번 Phase A의 고정 벤치마크
  세트로는 채택하지 않는다. KOSIS 문항 기반 벤치마크를 원하면 이사님 확인 후
  사람이 직접 표를 내려받아 설문지를 맞추는 후속 작업이 필요하다.

### (b) 통계청 사회조사 마이크로데이터 (MDIS 경유) — ⛔ 막힘 (신청·승인 필요)

- 확인 방법: 2026-11-23 웹 검색 (MDIS 이용 절차, 통계청 예규
  「인가된 통계자료 이용절차 등에 관한 규정」).
- 확인된 절차:
  1. MDIS 홈페이지(https://mdis.kostat.go.kr) 회원가입·로그인
  2. 이용신청서(연구계획서 포함) 제출 → 자료작성부서 심사 → **승인 (신청일로부터
     14일 이내)**
  3. 승인 후 수수료 결제, 공공용 마이크로데이터는 온라인 다운로드 가능
  4. 승인용(인가된) 마이크로데이터는 RDC/SDC 이용센터 방문 분석만 가능하고
     반출에도 별도 승인이 필요함
- **이 지점에서 멈춤.** 지시대로 우회 시도·가짜 계정·비공식 경로는 시도하지 않았다.
  MDIS 마이크로데이터를 쓰려면 이사님(또는 지정된 연구책임자)이 직접 회원가입 →
  이용신청서(연구계획서) 제출 → 승인 대기가 필요하다. 소요 기간은 승인까지
  약 2주 내외로 안내돼 있다.
- 결론: 본 벤치마크는 MDIS 자료로 교체 가능하도록 구조만 잡아두고, 당장은 (c)의
  임시 벤치마크로 측정한다.

## 2. 임시 벤치마크 (이번 Phase A·B에서 실제 사용)

- **설문**: `samples/sample_questionnaire.json` (온라인 쇼핑 만족도, 6문항)
  - Q1 단일선택 (쇼핑몰), Q2 다중선택 (선택 요소), Q3·Q4 5점 리커트,
    Q5 주관식, Q6 단일선택 (월 쇼핑 횟수)
- **실측 데이터**: `samples/sample_real_data.xlsx` — 실제응답 200건
  (앱 내장 데모 실측 데이터. 출처·수집 방법은 `samples/make_samples.py` 참조)
- **합성 데이터**: 동일 설문·동일 페르소나 분포(DEFAULT_PERSONA)로
  분포추출(elicitation) 전략 + Gemini `gemini-2.5-flash-lite`로 200건 생성.
  생성 시드·배치 크기·모델은 베이스라인 리포트에 기록한다.
- **주의**: 이 200건은 데모용 실측이며 통계청 실측이 아니다. 여기서 잰 지표는
  **임시 베이스라인**이며, MDIS 자료가 확보되면 동일 지표로 다시 재야 한다.
  리포트·실험 결과에는 항상 "임시 벤치마크(샘플 200건)"임을 명시한다.

## 3. 지표 정의 (고도화 계획 §3 축 B·§6)

| 지표 | 정의 | 대상 문항 |
|---|---|---|
| 평균 오차 | 문항별 \|합성 평균 − 실측 평균\|의 평균 (서수 문항만) | Q3, Q4, Q6 |
| SD 비율 | 합성 표준편차 / 실측 표준편차 (서수 문항, 평균) | Q3, Q4, Q6 |
| 변이율 VR | 한 선택지가 95% 이상을 차지하는 문항 비율 | Q1, Q3, Q4, Q6 (단일선택·리커트) |
| JSD | 합성 분포와 실측 분포 간 Jensen-Shannon Divergence (밑 2, 0~1), 문항 평균 | Q1, Q3, Q4, Q6 + Q2는 보기별 Bernoulli JSD 평균 |
| 소수 의견 재현율 | 실측에서 10% 이상인 선택지 중 합성에서 5% 이상 나오는 비율 | Q1, Q3, Q4, Q6 + Q2 보기별 |

- 서수 코딩: 리커트 1~5 ("전혀 그렇지 않다"=1 … "매우 그렇다"=5),
  Q6은 "1회 이하"=1, "2~3회"=2, "4~5회"=3, "6회 이상"=4.
- Q2(다중선택)는 보기별 선택률(0~1 Bernoulli)로 다루며, 평균·SD는 보기별
  선택률의 평균 오차·표준편차 비율로 계산한다.
